# Hey, I’m Kabelo Motshabi Makgae 👋

**Data engineering · Applied machine learning · Full-stack development**  
📍 Pretoria, South Africa

I like following a problem all the way from raw data to the screen where someone can act on it. That might mean cleaning records in Databricks, serving a model through FastAPI, or building the React dashboard that makes its predictions easy to inspect.

I also evaluate AI-generated code, where my job is to reproduce failures and explain them with evidence. Away from the keyboard, I play guitar. 🎸
